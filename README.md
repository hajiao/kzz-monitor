# 可转债后台监控 1.0

这是原 `kzz.py` 的独立重构版，采用 **后台 Python/EXE + Excel 配置面板**。它不依赖 Excel 一直打开，比纯 VBA 更适合长时间运行、开机自启动、交易日判断和邮件提醒。

> 行情、评级和提醒仅用于个人数据整理，不构成投资建议。务必先用少量转债验证数据源和提醒阈值。

## 已实现

- 每次只处理一只转债，默认间隔 60 秒，间隔可在 Excel 中设置（最低 10 秒）。
- 支持独立的“整轮间隔分钟”：按两轮开始时间计算；若一轮耗时超过该间隔，则不再额外等待。
- 从 AKShare 获取实时行情、强赎信息和近一年历史最高价；所有行情接口封装在 `provider.py`，以后可替换。
- 通过 AKShare 的新浪交易日历判断当天是否开市，接口失败时“安全停止”，不会仅凭周一至周五误判。
- 所有调度固定使用北京时间，不受电脑或打包环境的系统时区影响。
- 只在 09:30–11:30、13:00–15:00 轮询；收盘后完整更新一轮，然后休眠到下一交易日。
- 从安道全 Excel 导入评级、建仓线、加仓线、重仓线。
- 记录短期价格序列并判断上升、下降或震荡。
- 卖出提醒：监控峰值超过“卖出观察价”，当前进入下降趋势，且从监控峰值回撤达到设定百分比。
- 建仓、加仓、重仓区域进入提醒。
- Windows 桌面通知、SMTP 邮件、滚动日志和 Excel 提醒记录。
- SQLite 保存价格和提醒状态；程序重启后不会立即重复提醒。
- 支持无控制台 EXE、登录自启动和每天 09:20 计划任务。
- 支持基于 JSON 清单的一键在线更新；更新包不含且不覆盖用户 Excel、数据库和日志。

## Excel 面板

首次初始化会生成 `可转债监控.xlsx`，包含：

1. **设置**：轮询频率、开收盘时间、安道全路径、通知开关。
2. **监控列表**：代码、卖出参数、三段线、行情、趋势、回撤及状态。
3. **提醒记录**：所有已触发提醒。

程序运行时会写入该文件。Windows Excel 会锁定正在打开的文件；查看完配置后应关闭 Excel。即使面板暂时被锁，后台行情和通知仍继续，错误会写入日志。

### 卖出提醒参数

- `卖出观察价`：只有监控期间的峰值达到该价位后，卖出条件才会“武装”。
- `回撤提醒%`：`(监控峰值 - 当前价) / 监控峰值 × 100`。
- `趋势窗口`：使用最近几次轮询价格；默认 3。
- `趋势最小跌幅`：窗口首尾至少下降该绝对价格，且下降步数不少于上升步数，才判为下降。

同一轮下跌只提醒一次；回撤恢复到阈值的 40% 以下后自动解除锁定，后续再次下跌可以重新提醒。

## 安装和初始化

1. 安装 Python 3.10 或更高版本。
2. 在 PowerShell 中进入本目录，运行 `build.ps1`。脚本会使用独立 Python（不能使用 Conda Python）建立 `.venv-build`、安装依赖、生成 `release/KzzMonitor.exe`，并自动检查 SSL/SQLite DLL。
3. Python 版首次初始化：`.venv\Scripts\python.exe -m kzz_monitor init`。
4. EXE 版首次运行：`release\KzzMonitor.exe init`。

初始化会尝试从上级目录的 `kzz_vba.xlsm` 导入转债代码。不会覆盖已经存在的面板。

## 使用

- 直接双击 `KzzMonitor.exe`：打开控制台并自动启动监控；关闭窗口会缩到系统托盘。
- 控制台运行：`release\KzzMonitor.exe run`
- 无界面运行（高级用途）：`release\KzzMonitor.exe headless`
- 立即完整更新一次：`release\KzzMonitor.exe once`
- 测试提醒：`release\KzzMonitor.exe test-notify`
- 手动导入安道全：`release\KzzMonitor.exe import-adq "D:\路径\安道全.xlsx"`

持续运行时，每轮开始都会重新读取 Excel 设置。修改配置后关闭 Excel，最迟在下一轮生效。

`release` 文件夹可以整体复制到没有安装 Python 的 Windows 电脑。运行时不需要 Python、pip、AKShare 或其他包；这些内容已经打入单个 EXE。需要同时保留 `可转债监控.xlsx`，因为它是可编辑的配置和结果面板，而不是程序依赖。

控制台可以查看实时日志、启动/停止监控、保存常用时间和通知设置、打开监控表。点击窗口关闭按钮不会退出，而是隐藏到 Windows 托盘；双击托盘图标可恢复。右键托盘图标可以显示控制台、启动、停止或彻底退出。

控制台操作按钮：

- **开启轮询/结束轮询**：启动或停止后台监控线程。
- **立即强制新一轮**：不考虑当前是否开市，马上开始一轮完整更新；各转债之间仍遵守轮询间隔。
- **刷新安道全**：马上重新读取设置的安道全文件，按代码覆盖评级和三段线。
- **测试邮件**：保存当前 SMTP 设置并发送一封测试邮件。
- **操作手册**：打开同目录的详细离线 HTML 手册；HTML 不存在时尝试 PDF。

## 邮件设置

邮件可以直接在控制台设置：

- SMTP 服务器，例如 `smtp.qq.com`；
- SMTP 端口，SSL 通常为 `465`；
- SMTP 用户名；
- SMTP 发件人；
- 是否使用 SSL；
- SMTP 授权码；
- 收件人，多个地址用英文逗号分隔。

授权码通过 Windows DPAPI 按当前 Windows 用户加密保存在 `data/smtp_secret.bin`，不会写入 Excel。加密文件复制到其他用户或其他电脑后无法解密，需要重新输入授权码。

仍然兼容以下用户环境变量，适合高级部署：

- `KZZ_SMTP_HOST`：SMTP 服务器，例如 `smtp.qq.com`
- `KZZ_SMTP_PORT`：SSL 常用 `465`
- `KZZ_SMTP_USER`：登录用户名
- `KZZ_SMTP_PASSWORD`：邮箱提供商生成的 SMTP 授权码，不是网页登录密码
- `KZZ_SMTP_FROM`：发件地址，通常与用户名相同
- `KZZ_SMTP_SSL`：`true` 使用 SSL；`false` 使用 STARTTLS

设置环境变量后要重新启动程序。不要把授权码写进工作簿、脚本或聊天消息。

## 自启动和定时启动

运行 `install_startup.ps1` 会注册当前用户的计划任务 `KzzMonitor`：

- 用户登录时启动，适用于开机后后台常驻；
- 每天 09:20 再触发一次，保证开盘前启动；
- 重复实例会被忽略，程序自身也有单实例锁；
- 程序内部最终以交易日历和开闭市时间为准。

运行 `uninstall_startup.ps1` 可移除计划任务。计划任务使用当前用户权限，不要求管理员权限。

## 数据和日志

- `data/monitor.db`：历史轮询价格、每日最高价缓存、提醒去重状态。
- `logs/kzz_monitor.log`：运行日志，每天轮换。
- Excel 被占用或网络接口暂时失败时，程序会记日志并在 60 秒后重试。

## 数据源适配

AKShare 或上游网站字段变化时，只需修改 `kzz_monitor/provider.py`：

- `refresh_spot()`：实时行情和强赎信息；
- `one_year_high()`：历史行情；
- `is_trade_date()`：交易日历。

轮询调度、Excel、提醒逻辑不需要随数据源一起改动。
